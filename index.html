Proyecto Clave

Migración Bus12C → Microservicios REST JSON

Lideré la certificación y validación técnica del proceso crítico de migración del Bus de integración legado (Bus12C) hacia una arquitectura moderna basada en microservicios REST JSON.

Mis Actividades en este Proyecto:
  • Verificación de equivalencia funcional: Garantizar que el comportamiento del nuevo sistema sea exactamente el mismo que el anterior.
  • Comparación SOAP vs REST: Contraste de cargas útiles (payloads), tipos de datos y códigos de estado.
  • Validación de transformaciones: Certificar el flujo de datos hacia sistemas y bases de datos legadas.
  • Certificación técnica de servicios: Aprobación de despliegues en producción de endpoints críticos.
  • Automatización de pruebas: Desarrollo parcial de flujos automatizados usando Apache JMeter para simular cargas de concurrencia.
  • Mocks: Implementación de mocks en SoapUI y Mockoon para desacoplar dependencias no migradas durante las pruebas.
